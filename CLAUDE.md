# CLAUDE.md

Translation data for the Tenacity client (`lang/`) and website (`web/`). English is the source.

- `lang/**/en.lang` is generated by `tools/lang-catalog.mjs` in the client repo, and `web/en.json` is copied from the
  site's `messages/en.json`, `legal/en` from its `content/legal`. Never edit them here.
- The client reads `manifest.json` for the active version, so bumping `active` needs that version's folder complete.
- Run `node --test` and `node scripts/check.mjs` before committing.
- `translate.mjs` keeps hand edits. To force a retranslation, delete the key's entry from the locale file.
- Everything here is public and shown to users: no secrets, internal names or unreleased features.
- You own every commit, including AI-written ones. Never add AI-attribution trailers.
